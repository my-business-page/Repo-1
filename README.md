# Studio June — Link-in-bio specimen

A responsive, editorial-style link-in-bio page concept created as a specimen for Mad Web Studios.

## Files
- `index.html` — page structure and editable demo content
- `style.css` — responsive styling, palette, motion, and layout
- `script.js` — scroll reveal and a clearly labelled demo-only signup interaction

## Before using for a real person or business
1. Replace the Studio June name, biography, social profiles, and all example links in `index.html`.
2. Replace the sample WhatsApp number (`6500000000`) with the correct business number in international format.
3. Connect the signup form to a real email platform if collection is needed. The current form does not send or store data.
4. Replace or remove any links that do not apply.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. GitHub Pages may take a few minutes to publish.

This is a static, front-end specimen. No backend or external form service is configured.
